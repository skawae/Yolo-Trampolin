# Yolo-Trampolin
## 現在の進捗

### 着地位置の保存
・Yoloを用いて、人物推定と姿勢推定ができている。
・2DDLT法を使用して、トランポリンベットの外枠（青）と内枠（赤）をクリックで定義して、着地位置を
一枚の画像に保存することができる。
・着地判定は、赤枠を基準として、人物の速度が０になったとき、着地した判定をしている。

### 着地時の姿勢推定と各関節部の角度計算
・着地時の姿勢推定は完了
・姿勢推定時の各関節部の角度計算も行っている。
・各着地時の画像と骨格、各関節部の角度、着地回数を入力している画像での保存もしている。
＝＞それらを入力動画の名前のフォルダでまとめている。

### Trampoline_pose_final_v2.py
・Yolov8-poseを使用し、人物の姿勢推定を行う
・着地時の姿勢を抽出し、以下の点を抽出する
    ・着地地点
    ・前回の着地地点から現在の着地地点までの総距離
    ・膝関節角度
    ・腕上げ角度
    ・頭部傾き角度
    ・腰上半身角度

・キャリブレーションをする際に、手動で外枠の4点, 内枠の4点,を取る
・入力＝動画
・出力＝スケルトンポーズを追加した動画, 各姿勢を抽出したcsvファイル, 着地地点の俯瞰図

###　gra.py
・GRA（グレイリレーショナル分析）を行う。
・入力＝csvファイル
・出力＝各項目の相関度
